# Roadmap

## v0.1: reproducible Ada Windows release

- Import and audit the CUDA runtime source baseline.
- Preserve upstream license and notice obligations.
- Fix CUDA architecture configuration so `TF_CUDA_ARCHITECTURES` is explicit.
- Ship an Ada `sm_89` Windows x64 build.
- Ship CLI, repacker, OpenAI-compatible server, diagnostics, and quick benchmark scripts.
- Document 4 GB, 6 GB, 8 GB, and full-resident VRAM behavior.
- Fix Windows Unicode CLI argument handling.

## v0.2: release engineering

- Stage redistributable Windows x64 archives for `legacy` and `modern`
  profiles (`scripts/package-windows.ps1` is now available).
- Add release checks for binaries, model installation, and server health.
- Checksums and build metadata are generated by the packaging script; upload,
  release notes, and Windows code-signing support remain before publication.
- Provide an installer or bootstrap script that detects driver, compute capability, VRAM, RAM, and storage.

## v0.3: architecture coverage

- Add validated releases for Ampere and Hopper after hardware testing.
- Decide whether a universal fatbin or per-architecture artifacts give the best distribution experience.
- Add Linux CUDA packaging after platform abstractions are audited.

## Non-goals for v0.1

- Generic GGUF, Safetensors, or arbitrary Hugging Face model support.
- A claim of support for all NVIDIA CUDA GPUs.
- Bundling model weights.
- AMD, Intel, or D3D12 production support.
